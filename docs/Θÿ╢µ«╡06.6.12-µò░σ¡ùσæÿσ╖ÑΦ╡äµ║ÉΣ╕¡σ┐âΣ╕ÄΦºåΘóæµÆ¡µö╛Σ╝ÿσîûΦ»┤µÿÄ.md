# 阶段 06.6.12｜AI 数字员工资源中心与视频在线播放优化

## 本次优化

### 1. 视频在线播放
- 资源详情优先展示“在线播放”，不再把视频误判成普通 FILE。
- `fileUrl` 即使实际指向 MP4/MOV/WebM，也会根据 MIME、原文件名、扩展名、storageKey 自动识别为视频。
- 本地资源 API 支持 Range / 206 Partial Content、Accept-Ranges 与流式读取，适合浏览器视频拖动、进度读取与大文件播放。
- 当旧资产缺失 MIME 时，播放 API 会依据扩展名补齐 `video/mp4`、`video/webm`、`video/quicktime` 等 Content-Type。
- 视频失败时提供“新窗口打开 / 下载视频”兜底，并提示优先使用 MP4（H.264 / AAC）。

### 2. 10 大 AI 超级员工 → AI 数字员工矩阵
- 首页展示语言改为“AI 数字员工 / AI DIGITAL WORKFORCE”。
- 从普通产品卡片调整为岗位矩阵：岗位序号、数字员工标识、职责标签、能力标签、进入岗位。
- 桌面端默认 5 列，让 10 个岗位完整形成 2 行矩阵，减少页面纵向浪费。
- 增加“内容生产 → 品牌 IP → AI 获客 → 客户转化”的工作流提示，让用户理解这些不是 10 个孤立工具，而是一支可协同的数字员工团队。

### 3. 资源中心 UI
- 首页与资源中心统一使用功能区块：Skills、Prompt、教程与手册、产品下载、行业资料与资源。
- 区块增加“能力库 / 表达库 / 上手区 / 交付区 / 资料区”语义标签。
- 资源中心首页强化“AI 数字员工资源工作台”的定位，减少普通文件库感。
- 保留统一返回入口与独立模块路由。

### 4. 后台资源中心编排
- 增加前台实时预览条。
- 模块编辑默认折叠，避免五个模块同时显示成超长表单。
- 每个模块只在需要时展开编辑，减少后台操作干扰。

## 格式建议
公开视频建议统一使用：`MP4 / H.264 视频编码 / AAC 音频编码`。如必须保留 MOV / HEVC，前台仍会尝试播放，但不同浏览器和设备的兼容性会更弱。
