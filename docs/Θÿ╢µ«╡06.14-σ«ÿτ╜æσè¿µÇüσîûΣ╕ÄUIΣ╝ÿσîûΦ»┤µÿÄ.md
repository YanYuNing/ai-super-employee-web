# 阶段 06.14：官网动态化与 UI 优化说明

## 目标

围绕“AI 数字员工”产品定位，统一优化首页 Hero、10 大 AI 数字员工、解决方案、关于我们，并把关键文案/任务状态真正接入 CMS。

## 本次改动

### 首页 Hero
- Hero 右侧“正在执行：装修行业关键词曝光任务”不再依赖固定 JSX 文案。
- 优先读取 `home` 页 `hero` 区块 `data.task`：`status / agent / title / mode / meta / progress`。
- 兼容旧数据：仍可从 `site.home` 旧配置字段读取，避免历史数据升级后前台空白。
- 浮动员工状态从 `hero.data.floatingStatuses` 读取。
- 后台“首页可视化编辑”中增加 Hero 执行卡的结构化编辑入口，保存为嵌套 `task` 对象。
- 视觉上增强执行卡的层级、进度条、Live 状态和 AI 数字员工氛围。

### 10 大 AI 数字员工
- 文案定位从“工具列表”强化为“AI DIGITAL WORKFORCE / DIGITAL EMPLOYEE”。
- 岗位数量继续从产品库动态计算，不写死 9/10。
- 卡片增加角色、能力标签、能力 chips 与进入岗位 CTA。

### 解决方案
- 首页行业方案改为“行业增长场景卡”，增加行业定位、内容/获客/转化工作流和 CTA。
- `/solutions` 列表改为 3 列行业作战卡，增加行业描述、工作流标签、场景数量和 CTA。
- `/solutions` 的标题、描述、CTA 文案可以从 `cards` 区块字段管理。

### 关于我们
- 删除对异常 `0100000` 页面正文的直接依赖；当 CMS 内容看起来像异常占位值时，前台自动使用安全默认文案。
- Hero 增加 AI 数字员工系统卡，数据直接读取“关于我们” Body 区块中的 stats。
- Body 区块支持动态标题、副标题、正文、核心指标、价值原则。
- Body 区块上传的图片/视频现在会真正渲染到前台。
- 额外区块继续支持动态标题、正文、图片和视频。
- 后台“页面内容”增加关于我们核心指标与价值原则的结构化编辑器。

### 数据修复
提供 `npm run repair:stage06.13`：
- 修复 About Body 异常正文占位值。
- 补齐 About 核心指标与价值原则默认数据。
- 补齐 Home Hero 执行卡动态数据。
- 补齐 `site.home` 兼容字段。

## 建议部署后做的真实验收

1. 后台首页可视化编辑 → 修改 Hero 任务标题/状态/进度 → 官网刷新确认实时变化。
2. 后台页面内容 → 关于我们 → 修改标题、正文、指标、价值原则 → 官网刷新确认变化。
3. 上传 About Body 图片/视频 → 官网确认能显示/播放。
4. 后台解决方案 → 修改发布状态 → `/solutions` 与首页同步。
