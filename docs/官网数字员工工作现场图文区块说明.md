# 官网「AI 数字员工工作现场」动态图文区块

## 前台实际展示位置

1. **官网首页 `/`**：位于「10大 AI 数字员工」矩阵下面、AI Claw 介绍模块上面。只显示数据库中已启用且有标题的前 3 项。区块锚点为 `#employee-showcase-home`。
2. **产品中心 `/products`**：位于现有数字员工产品卡片列表下面、页面其他扩展内容和 Footer 之前。展示全部已启用项目。区块锚点为 `#employee-showcase-products`。
3. 两个位置不使用两套内容，也不使用静态截图回退；都读取 `pages.slug = products` 对应的 `page_sections.sectionKey = showcase` 数据。

## 数据与图片如何动态化

- 区块标题、副标题、按钮、卡片标题、分类、描述、跳转地址、图片说明、排序、启用状态，保存在 `page_sections.data` JSON 中。
- 60 张初始截图导入现有 `media_assets` 表，文件记录包括名称、类型、文件大小、存储方式、存储 Key、文件夹、说明和图库序号。
- 图片文件按当前文件存储配置放到本地存储目录或 OSS；CMS 记录保存 `/api/public/assets/{id}` 和 `imageAssetId`，前台通过统一的公共资产 API 读取。数据库保存资产元数据与引用，二进制文件由现有文件存储系统管理，不把大文件作为 BLOB 塞入 MySQL。
- 新上传图片会先进入文件素材库，再把资产 ID 和公共 URL 保存到 CMS JSON。切换图片会更新该展示项；清除图片会把 `imageUrl` 清空并切换到纯文字样式。
- 前台主页和产品中心设置为动态渲染，不使用写死的展示数组作为内容来源。

## 后台编辑位置

进入 `后台管理 → 页面内容 → 产品中心 → AI 数字员工工作现场（Key: showcase）`：

- 编辑区块标题、副标题、英文小标题和按钮文字/链接。
- 每项支持编辑展示标题、分类、说明、跳转地址、图片 Alt、启用状态、顺序。
- 「数据库截图库」从 `media_assets` 里筛选已入库的 60 张截图；也可以通过「上传图片 / 从素材库选择」上传一张新图或选其他素材。
- 「预览首页展示区」链接到 `/#employee-showcase-home`；「预览产品中心展示区」链接到 `/products#employee-showcase-products`。
- 首页只取前 3 个启用项；产品中心展示全部启用项。调整顺序会同步影响两个位置。

## 首次部署/启动

在项目根目录运行。先备份当前数据库，并保留正在使用的 `.env`，不要用 `.env.example` 覆盖已经配置好的连接信息。

### Windows PowerShell

```powershell
# 1. 仅在不存在 .env 时创建；已有 .env 不要覆盖
if (!(Test-Path .env)) { Copy-Item .env.example .env }

# 2. 确认 .env 里的 MySQL/MariaDB 连接、会话密钥和文件存储配置正确，再安装依赖
npm ci

# 3. 按当前 Prisma 7 schema 生成客户端
npm run prisma:generate

# 4. 将 60 张截图导入媒体资产表，并将产品中心 showcase 区块写入数据库（幂等，可安全重跑）
npm run seed:employee-showcase

# 5. 启动开发环境
npm run dev
```

### Linux / macOS

```bash
# 仅首次创建；已有 .env 不要覆盖
[ -f .env ] || cp .env.example .env

npm ci
npm run prisma:generate
npm run seed:employee-showcase
npm run dev
```

然后打开：

- 官网首页：`http://localhost:3000/#employee-showcase-home`
- 产品中心：`http://localhost:3000/products#employee-showcase-products`
- 后台内容编辑：`http://localhost:3000/admin/pages`，切换到「产品中心」

## 生产部署

先备份数据库和当前上传目录，再同步代码、配置 `.env` 和安装依赖：

```bash
npm ci
npm run prisma:generate
npm run seed:employee-showcase
npm run build
npm run start
```

脚本会根据后台当前文件存储配置使用 LOCAL 或 OSS。若使用 LOCAL，确保 `LOCAL_UPLOAD_ROOT` 指向持久化磁盘目录，并在后续部署中保留该目录；若使用 OSS，确保 Bucket 的 Put/Get 权限和网络访问正常。

此功能沿用已有 `pages`、`page_sections` 与 `media_assets` 表，不新增 Prisma 模型，因此不需要为此执行 `prisma db push`。不要在已有生产数据库上为了此功能随意运行会重建或覆盖业务数据的数据库初始化命令。

## 验收清单

1. `npm run seed:employee-showcase` 输出 60 张图库记录同步完成。
2. `/api/admin/employee-showcase-gallery` 在管理员登录后返回数据库里的截图列表。
3. 首页 AI 数字员工矩阵下面可看到 3 张精选卡；AI Claw 模块在其后。
4. `/products` 的产品卡片列表后显示所有启用项。
5. 后台把一项换成不同截图并保存，刷新首页/产品中心后显示更新后的图；修改文字、排序、启用状态同样生效。
6. 清除某项图片并保存后，前台对应卡片显示科技感纯文字样式，不留空白图片框。
