# 资源中心区块化改版说明

本次改版的目标是让客户端通过一个“资源中心”入口统一访问不同类型的资源，而不是把 Skill、Prompt、使用手册拆成彼此分散的资源条目。

## 客户端结构

资源中心现在按照功能类型分区：

1. Skills 技能库
2. Prompt 提示词
3. 教程与使用手册
4. 产品下载、行业资料等其他资源（作为次级区块统一承载）

Skill 与 Prompt 仍然使用各自独立的数据模型和详情页；新增一条 Skill 或 Prompt 不会新增一个资源中心配置入口。资源中心只管理“区块”的展示顺序、名称、说明与入口。

## 后台结构

新增可直接进入的“资源中心”编排入口 `/admin/resource-hub`，用于调整区块顺序、标题、说明、入口地址和显示状态。

Skill 与 Prompt 仍保留独立列表管理入口，分别负责具体内容的新增、编辑、删除、发布和版本维护。

原有“资源资料”列表继续用于维护 Resource 类型内容，避免把内容数据和资源中心的展示编排混在一起。

## 数据与兼容

本次改版没有新增 Skill、Prompt、使用手册的重复数据表，也不要求每次新增内容都写入资源中心区块配置。资源中心区块通过现有数据查询动态生成内容列表，并读取资源中心页面的区块配置进行展示顺序和文案覆盖。
